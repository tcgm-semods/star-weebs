# Star Weebs

This gives ships curves.

A Star Empire mod that replaces ship hull art with anime-girl
(kanmusu-style) alternatives. Currently covers `250Capital`, `250Carrier`,
and `250CombatFreighter2` -- everything else keeps its normal hull art.

![Star Weebs screenshot 1](.github/images/razgrizScreenshot.png)
![Star Weebs screenshot 2](.github/images/razgrizScreenshot2.png)

## Install

Grab the latest `.semod` from [Releases](../../releases/latest) and drop
it into the Star Empire Mod Manager.
